### A Dungeon Adventure

This is a one-level game which is the first game I made in Unity. The game is inspired by titles like Zelda, and takes place in a dungeon, where puzzles and scary spiders challenge you when trying to reach the end of the level. If the challenges are overcome, a big boss is waiting for you, giving you one last challenge.

### Otherworld Guardian

This is a group project from a course at KTH. The adventure starts when you, playing as Beep the robot, spawn into the mystical and vibrant world of Celestria. As you arrive, you find out that you stand at the threshold of a realm shrouded in enchantment and peril. The once serene lands are now overshadowed by a creeping darkness, brought on by a malevolent force fueled by the Fungal Foes. The inhabitants of this world are in desperate need of salvation. The game combines world exploration with instances of puzzles.

### Hemsida

Hemsida is Webpage in Swedish, and this is a project where I programmed a web version of my CV. I included a Pokemon quiz which lets the user guess Pokémon names based on images, and collect points based on the amount of correct answers, up to 10. The app uses the api PokéApi to retrieve information about the Pokémons.

The webpage can be found at https://lucascv.vercel.app/
