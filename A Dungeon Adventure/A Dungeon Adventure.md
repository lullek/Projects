## A Dungeon Adventure

This is a game I made in Unity with C# as a project for the course DD2323 at KTH. I had really fun working on the project, and I worked a lot more on it than I had to because it was fun to learn Unity. I have built the game myself from scratch using assets from the Unity Asset Store for graphics.
